## 核心结论（v1.7.9 数据）

1. **favens v1 系统性偏狼的根源 = 行为注入层无代价端**（弃票/护短/红线全是纯增益）；v2 机制下沉引擎并带代价端后，**Δwolf 点估计收敛至 ±2pp**——"规则在引擎、策略在 AI、权能有代价端"命题方向成立（严格统计表述见 §边界条件）。
2. **局四 v2 落带**：51.57%[50.3,52.8] PASS；局八 46.4/十五人 43.0 FAIL 为 M0 已知基线擦边（v2 未使其恶化）。
3. **时序敏感性待外生化验证**：原始三桶极差 26-36pp 为逆向因果（狼强→早刀丘比特），非机制敏感直接证据；bot 局解绑未触发（策略待迭代）。

## 统计口径（v1.7.9 修正，必读）

- **Δwolf 定义**：`Δwolf = wolf_v2 − wolf_ctl`，**正值 = v2 相对 ctl 偏狼，负值 = 偏好人**。修正记录：初版脚本 `−d` 实为 `ctl − v2`（正值=变好人），与意图相反——已修（lover-regress.js），2026-08-07 重汇总。
- **落带判定（配置独立，绝对带）**：单变体 wolf% 的 Wilson 95% CI ⊂ **[45,55]** 即 PASS（点估计不作数）。各配置独立判定，不做跨配置合并。
- **边界条件（重要）**：M3 的"机制中性"结论成立范围为 **"解绑未触发的 bot 局"**——bot 解绑策略（M3.5）尚未实现，解绑机制在 3000×6 局中从未被触发（loverMeta.unbindUsed 恒 false）。因此 Δwolf ≈ 0 不代表"解绑机制本身平衡"，只代表"未含解绑的 v2 其余机制（普通狼刀法/守护/复仇/保丘比特）相对基线无系统性偏移"。
- **统计精度（降级表述）**：各配置 3000 局，Δwolf 的配对 CI ≈ ±2.5pp，**单配置点估计 |Δ|≤2pp 不显著**（多数 CI 含 0；唯一显著项 = 十五人 −1.87pp，CI [−3.5,−0.2]，v2 偏好人）。**结论表述应为"无强偏狼证据（点估计 |Δ|≤2pp）"，而非"机制中性已证明"**。
- **符号修复后的方向汇总**（2026-08-07 重算）：局四 −1.33 / 局五 −0.63 / 局六 +1.10 / 局七 +0.03 / 局八 +0.17 / 十五人 −1.87——方向混杂（3 偏好人 3 偏狼），无系统性偏狼。

## M3.5（解绑激活验证 + A/B 注入，2026-08-07）

**背景**：M3 回归组解绑触发率 0%（自然对局丘比特少死——bot 狼不刀丘比特、丘比特不被票，解绑窗口极小）。解绑作为 v2 修复投票免疫的核心一刀，在平衡验证中从未被激活——①验证盲区成立。为此做三组注入实验（局四 v2，同池 3000 局/组）：

| 组 | 注入 | 解绑 | wolf% | 解绑次数 |
|---|---|---|---|---|
| G1 | cupid-dead-n1（首夜必死） | 解锁 | 51.23% | 1018（33.9%） |
| G3 | cupid-dead-n1 + loverLocked | 锁定 | 54.73% | 0 |
| IM(参考) | cupid-immortal（必活） | 锁定 | 44.33%（n=300） | 0 |

**解绑机制单独效应 = G1 − G3 = −3.50pp（利好好人）**，验收 |Δ|≤5pp PASS。方向与设计一致：解绑消除"投票免疫绑架"，狼恋人失去免死金牌。

**推论（真人局平衡风险，重要）**：bot 局解绑休眠（丘比特少死）→ v2 ≈中性（51.57，Δ−1.33 不显著）；**真人局好恋人会主动解绑 → 解绑激活 → 预期 v2 偏好人 ~3.5pp**（51.57−3.5≈48，可能出带下界）。**bot 局落带 ≠ 真人局落带**——真人局需实测或先启用"解绑暴露度"杠杆（连续杠杆①，0-1，调解绑代价）对冲。

**A/B 基建（含踩坑记录）**：
- `loverTest`（'cupid-dead-n1'首夜必死 / 'cupid-immortal'免疫一切死亡）+ `loverLocked`（解绑禁用，G3）经 pool 场景透传；result.loverMeta 记录解绑/时序
- **踩坑**：`exilePlayer` 豁免路径曾直接 return（无新定时器 + phase 停驻 'vote'）→ lab 虚拟时钟卡死 → stall 兜底重试（单局数分钟）。修复：豁免 = 放逐无效入夜（pushEvent exile_immune + votes 重置 + checkWin + beginNight），冒烟 5.5s/20 局 0 timeout
- immortal 组结构性慢（丘比特不死 → 狼无法屠民，对局拉长），全量 3000 局不现实，取 300 局参考
