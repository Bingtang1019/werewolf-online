# archive/v5-投票判定实验 —— V5 主干判定（路径 A vs B，2026-08-08）

> **性质**：架构判定实验归档（非模型文件）。结论：**路径 B（策略学习，无前瞻）成立**——狼人杀投票不需要前瞻，rollout 退役。
> **触发背景**：层级自举（三档全提 simulate_v2）后 12a 系统性偏狼 +22~30pp，归因发现 rollout"单视角模拟"是结构性缺陷。
> **2026-08-08 二次修订**：300 局配对 + 分侧覆盖审计后，归因修正（见第八、九节）——早期"43.1% vs 54.4%"为小样本直测假象，真值见下表。

## 一、归因结论（为什么 rollout 负增益）

| 证据 | 值（早期小样本） | 值（大样本真值，见第八节） |
|---|---|---|
| 好人侧 rollout 命中真相（投狼） | 43.1%（1572 票审计） | **49.1%**（1476 票，simulate 档） |
| decideVote 命中真相 | 54.4%（+11.3pp） | **61.5%**（+12.4pp） |
| rv≠dv 分歧率 | 36.5%（573/1572） | **34.6%**（510/1476） |
| 分歧票中 rv 更好 / dv 更好 / 都错 | 63 / 241 / 243（dv 4:1 碾压） | 大样本：dv 系统性优于 rv（-12.4pp） |
| rv 高 margin（≥0.3）仍错 | 大量（margin 机制无法兜底） | margin≥0.05 覆盖 94.3% 仍错（-12.4pp） |

**根因**：rolloutVote 模拟其他玩家投票用 **`world.scores`（当前 bot 自己的嫌疑分）**——假设"所有玩家共享我的视角"（单视角/独裁世界模拟）。现实是多 agent 异质（各自 scores + 卖狼/跟票/恋人红线/波动）→ 前瞻收益基于错误世界模拟 → 系统性投错目标。**这是模型错误，不是调参问题**。

**排除项（已实验证伪）**：价值模型视角（V_good/V_wolf/parse 均偏狼 68-77%）、符号反（修复后 68.0% 不变）、狼侧 rollout（去掉反而更偏 71.9%——但该对照为小样本，大样本见第八节狼侧审计）。

## 二、判定实验 1：投票预测器（路径 A 可行性）

**目标**：P(vote_i = j | 投票者视角, 候选集)——"别人会投谁"是否可学。

| 项 | 值 |
|---|---|
| 数据 | 999 局 12a（**vote_cast 逐票事件**，v2 生态 smart 档），33,168 票 / 277,839 样本对 |
| 特征 | voteFeatures 13 维公开信息（座位/发言/查杀声明/票型/自称/质疑/对跳/行为一致） |
| 模型 | MLP（hidden 64，BCE，按 botId 划分 80/20） |
| 泄漏修复 | 初版 100%（结算快照含后续票 + actionLog 含本次票）→ 逐票事件 + push 后置 → 51.6% |
| **预测器 top-1** | **51.6%**（全量 30 epochs） |
| 基线（投最高 votes_against） | 47.2% |

**口径审查（重要，防止误读）**：
- **51.6% 是"行为预测"口径**：预测对了**投票者实际投的人**（与真相无关——投票者可能投错人，预测对了他的错也算对）
- **54.4% 是"真相命中"口径**：**投中了狼**（与行为无关——decideVote 策略本身的质量）
- **两者不是同一测量，并排比较严格说不严谨**（一个是行为保真度、一个是决策质量）
- **但结论方向不受影响**：同质 bot 生态下，投票者的行为就是 decideVote 类策略的输出（行为克隆上限 ≈ 老师水平），实验 2 的 75.5% 输出保真补足了"可学性"证据——即"他人投票动力学"可学，但**学到的水平不超过现有启发式**（且成本高）。
- 未来引用这两个数字做对比时，必须注明口径差异（本段为强制引用注释）。

## 三、判定实验 2：BC from decideVote（路径 B 可行性）

**目标**：π(13维特征) → decideVote 输出（label = 审计的 dv——**纯规则策略输出，无 rollout 污染**）。

| 项 | 值 |
|---|---|
| 数据 | 500 局（vote_cast + rolloutAudit dv 标签按序对齐），92,770 样本对 |
| π(dv) top-1（输出保真） | **74.9%**（quick 75.5%，稳定；随机基线 9.5%） |
| 判定 | **✅ π 高保真克隆 decideVote 行为 → BC 有效 → 路径 B 可行** |

**语义**：75.5% = 候选集内正确选出"decideVote 会投的人"（行为克隆保真度）；decideVote 自身命中真相 54.4% 是 π 的**起点**（BC 只是初始化，PPO 微调后可超越老师）。

## 四、判定结论

| 路径 | 证据 | 判定 |
|---|---|---|
| **A**（VoteDynamics 修模拟失真，保留前瞻） | 预测器 51.6% < decideVote 54.4%（行为预测口径，见上）；动力学可学但强度弱于启发式；需 VoteDynamics + 重采 + 集成，成本高 | **否决** |
| **B**（策略学习 π(a\|s)，无前瞻） | π 高保真克隆 decideVote（75.5% 输出保真）；decideVote 是可靠老师（54.4%）；rollout 退役 → 性能 70 倍/超时结构性消失 | **✅ 成立** |

**战略结论**：狼人杀投票决策的正确形态是"**当前信念的正确运用**"（嫌疑分整合）而非"未来模拟"。前瞻（rollout）的模拟失真在狼人杀多智能体场景是结构性缺陷。

## 七、教训固化

- **数据泄漏两连**：结算快照泄漏后续票（→ 逐票事件）；actionLog 含本次票（→ push 后置）。**训练数据事件必须携带"决策时刻前"状态快照**，验收前先做特征均值对比（正负样本 Δ=1.0 的即泄漏）
- **口径纪律**：行为预测（投对实际目标）≠ 真相命中（投中狼）——不同测量不并排比较，模型卡强制注明
- **同质生态克隆上限**：bot 投票者 = 规则策略输出 → 预测器上限 ≈ 老师水平；"预测他人"与"克隆老师"在无真人对局时信息等价
- **小样本假象**（本次最重要的教训）：64 局功效 ±6-8pp，手动直测 rollout 裸输出（未经 margin 门控）——得出"43.1% vs 54.4%"的假象；300 局配对 + 覆盖审计修正为"49.1% vs 61.5%"。**归因结论必须大样本 + 生产链真实路径（含门控）**

## 八、归因修正（2026-08-08，三块证据补齐）

### ① 错误机制
早期"43.1% vs 54.4%"比较的是 **rollout 裸选择（未经 margin 门控）**——生产链中 margin<0.05 不覆盖。早期比较了一个"永远不会生效的分支"？**否**——大样本审计显示 margin≥0.05 覆盖 **94.3%**（rollout 并非被门控禁用，而是高自信地错）。早期错误在于**小样本（64 局）+ 手动直测口径**。

### ② 错误来源
- 64 局小样本（±6-8pp 功效，不可靠）
- 手动直测 rollout 输出（未经生产链路径）
- 早期"偏狼 68%"是**层级自举实验（LEVEL_MAP 全提 simulate_v2）的生态混淆**——smart 档被提到全链后行为变化，非 rollout 机制本身

### ③ 修正结论（300 局配对 + 覆盖审计）
- 好人侧 rollout 真值：**覆盖 94.3%（margin≥0.05），命中 49.1% vs dv 61.5%（-12.4pp）**——rollout 有害（非零贡献，是负贡献）
- 放宽阈值模拟（0.02/0.01）：覆盖略升（94.6-94.8%）命中不变（49.2%）——**无阈值可救**
- 当前生产链（smart 档 = useRollout=false）= **dv 全量**——12a 狼胜 47.7% **平衡**（"偏狼 68%"是层级自举实验的产物，已回滚）

### ④ 路径 B 判定理由修正
不是"rollout 有害"（负增益）→ 而是"**rollout 对好人侧是系统性负贡献**（-12.4pp）、对狼侧是正贡献（+8.5pp 投神职）"——**分侧管道**：好人侧 rollout 退役（π/dv），狼侧 rollout 保留。路径 B 依然成立，动机更纯粹。

### ⑤ 锚点修正
- **decideVote 真相命中大样本真值 = 62.6%**（早期 54.4% 同为小样本假象）
- **V5.1 验收锚点：62.6% +3pp**（信念引擎增益窗口以此为准）
- 早期所有引用 54.4% 的位置以上表真值为准（本文档已同步）

### ⑥ 狼侧分侧证据（大样本）
| 指标 | rv（rollout） | dv（decideVote） |
|---|---|---|
| 投好人率 | 100% | 100%（强制约束，无差异） |
| **投神职率** | **56.4%** | 50.3% |
| 分歧票（71.8%）投神职 | **57.3%** | 48.8%（+8.5pp） |

**分侧结论**：狼侧 rollout 有真实前瞻价值（投神职更准——狼知道队友 → 模拟失真小）；好人侧 rollout 系统性投错（-12.4pp）。**分侧管道决策确认**：好人侧 π/dv，狼侧 rollout 保留（V5.2 再考虑策略化）。
